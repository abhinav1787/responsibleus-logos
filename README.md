# Responsible Us — employer logos

Square (400×400, white-padded) employer logos shown on the job cards at
https://responsibleus.com/jobs, for employers whose own websites publish only a
tiny favicon. Built from the logo files hosted on Wikimedia Commons by
`integrations/responsibleus-site/logos/build_logos.py` in the agent repo, and
served through the jsDelivr CDN:

    https://cdn.jsdelivr.net/gh/abhinav1787/responsibleus-logos@main/logos/EMPLOYER-DOMAIN.png

Logos identify each employer on its own listing (nominative use); nothing is
altered beyond padding to a square.
